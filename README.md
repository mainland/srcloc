# The `srcloc` Package  [![Hackage](https://img.shields.io/hackage/v/srcloc.svg)](https://hackage.haskell.org/package/srcloc)  [![Actions Status: haskell-ci](https://github.com/mainland/srcloc/actions/workflows/haskell-ci.yml/badge.svg)](https://github.com/mainland/srcloc/actions?query=workflow%3Ahaskell-ci)

Data types for tracking, combining, and printing source code locations.

See the
[Data.Loc API documentation](https://hackage.haskell.org/package/srcloc/docs/Data-Loc.html)
for position conventions, optional offsets, location combination, and
upgrading from srcloc 0.6. The documentation is maintained in
[src/Data/Loc.hs](https://github.com/mainland/srcloc/blob/main/src/Data/Loc.hs).

## AI assistance

All contributions included in releases through version `0.6.0.1` were made
without AI assistance. AI tools were used in development, review, and release
preparation after that version, through version `1.0.0`. The maintainer remains
responsible for this release.
